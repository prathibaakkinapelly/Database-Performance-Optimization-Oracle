## Tools
- Oracle Database XE

## Description
This project demonstrates database performance optimization using
indexes, execution plans, and statistics on large datasets.
Designed and implemented a database performance optimization project on Oracle 21c XE by creating a large-scale OLTP schema with 100K+ records. Analyzed slow SQL queries and improved performance using indexing, query rewriting, materialized views, and PL/SQL bulk processing techniques.
